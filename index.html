התראות גם כשסוגרים את האתר?

אפשר להוסיף תוסף קטן ל־Chrome. האתר עצמו עובד מצוין גם בלעדיו.

↓ הורדת התוסף (ZIP)
איך מתקינים? דקה וסיימנו
  1. הורידי את קובץ ה־ZIP וחלצי אותו לתיקייה קבועה במחשב.
  2. פתחי ב־Chrome את chrome://extensions.
  3. הפעילי מצב מפתח / Developer mode בפינה העליונה.
  4. לחצי Load unpacked / טעינת פריט לא ארוז ובחרי את התיקייה שחילצת (זו שמכילה manifest.json).
  5. זהו. אם Chrome פועל וההתראות מאופשרות במחשב, תקבלי עד 3 תזכורות אקראיות ביום גם כשהאתר סגור.

טיפ קטן: אל תמחקי את תיקיית התוסף אחרי ההתקנה. הנתונים באתר ובתוסף נשמרים בנפרד; אפשר להעביר היסטוריה דרך ייצוא/ייבוא JSON.

התראות של אתר, לא תוסףהתזכורות פועלות כשהדף פתוח. להתראות גם כשהדף סגור צריך את תוסף Chrome.
